# Program ledger — Fleet Portal + Backend (complete flows)

Goal: complete the backend flows + build the Vue dispatcher portal. Mobile app deferred (next week).

## Architecture (rulings)
- **Backend:** extend the existing Express + TypeScript + Prisma app at `fleet-backend/` (SQLite for now). Same patterns: `requireAuth`, Zod `validateBody`, ownership-by-construction (queries keyed on token identity), Vitest + Supertest, per-unit commits scoped to fleet-backend paths.
- **Portal:** Vue 3 + Vite + TypeScript + Tailwind + Pinia (state) + Vue Router, at `fleet-portal/`. Talks to the Express API. Reuses the app's Tailwind palette (primary `#2563eb`) for visual continuity. Ruling — user chose Vue.
- **Auth for portal:** dispatcher role. Backend gains a `role` on the identity (driver | dispatcher) and dispatcher-only endpoints. Ruling — the dispatcher side is "designed, not recovered"; model it cleanly.
- **File uploads:** multer → local `fleet-backend/uploads/`, served static at `/uploads`, URL recorded. Ruling — no cloud storage in this build; swap to S3 later.
